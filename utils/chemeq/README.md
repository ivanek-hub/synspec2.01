### CHEMEQ  

The program equation for solving the chemical equilibrium equations (the equation of state), together with ist auxiliary programs. Thet are descibed in detail in Paper V.

- *chemeq.f*: chemical eqilibrium, or equation of state, solution

- *eos_modules.f*: auxiliary program for *chemeg*

- *eos_alloc.f*:   auxiliary program for *chemeq*

- *isotops*:       file with solar isotope fractions, needed for *chemeq*

- *eos.py*: a Python program for displaying the results of ^chemeq*. User instructions
and explanations are given at the header of the program.
